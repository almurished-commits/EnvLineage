# Roadmap

EnvLineage keeps its roadmap demand-driven. V0.1 focuses on trustworthy environment-variable lineage across JS/TS, env templates, Docker/Compose, and GitHub Actions.

Potential follow-ups, only when real usage justifies them:
- SARIF / GitHub code scanning output.
- Additional CI providers.
- Framework-aware adapters where framework semantics materially affect correctness.
- Kubernetes manifests.
- Additional application languages.
- Carefully scoped configuration and suppressions.
- Safe, narrow autofixes.

The project will not add features solely to inflate repository size or release activity.
